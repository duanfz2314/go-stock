# A股研究台（ashare-lab）

独立的 **A 股研究 Web 应用**，和桌面端 go-stock 并行存在。目标不是再堆 AI 功能和多市场行情，而是用免费公开数据，给出**能看懂、能落地**的个股研究结论。

## 为什么单独做这个

现有 go-stock 很强，但对日常研究不够“开门能用”：

- 桌面端（Wails）编译重，部分能力还和 VIP / AI Key 绑定
- 同时覆盖 A/港/美，信息面宽，主路径不是“这只 A 股值不值得继续看”
- 不少能力依赖付费大模型，或东方财富妙想 Key、问财 cookie 等
- 默认高频刷新，而多数研究其实用日频就够

本目录按三个约束实现：

1. **只分析沪深京 A 股**（含科创板、创业板、北交所股票，不含港美股、场内基金）
2. **只用免费公开数据**：东方财富延迟行情 / F10、财联社市场宽度、腾讯/新浪日 K
3. **数据频率按日频**：接口有 2–3 分钟缓存，不做 Tick / 分时盯盘

## 能做什么

- 市场总览：主要 A 股指数、涨跌家数、行业涨幅、成交额靠前个股
- 个股研究：行情、前复权日 K、财务快照、近 3 年 PE 分位
- **可解释研究评分**（估值 25 / 质量 30 / 趋势 25 / 资金 20）：结论是「进一步研究 / 纳入观察 / 谨慎 / 回避」，不是买卖点
- 条件选股：在成交额靠前的 A 股里按 PE、PB、ROE、市值、行业筛选
- 自选：存在浏览器本地，不上传

## 启动

需要 Python 3.10+，无第三方依赖。

```bash
cd ashare-lab
python3 -m unittest tests/test_analysis.py
python3 server.py
```

浏览器打开 http://127.0.0.1:8787

## 数据源

| 用途 | 来源 | 说明 |
|------|------|------|
| 指数 / 个股报价 / 行业 / 选股列表 | 东方财富 `push2delay` | 延迟公开行情 |
| 财务与 PE 分位 | 东方财富 F10 datacenter | 公开公司资料 |
| 市场宽度 | 财联社 x-quote | 涨跌家数、涨跌停 |
| 日 K | 腾讯财经，失败则新浪，再失败则东财 | 前复权日线 |

没有 Tushare token、没有东财妙想 Key、没有大模型。

## 评分不是荐股

分数用来缩小研究名单。ST、亏损（负 PE）、负债率过高等会单独标成风险。请自行阅读公告与财报。
